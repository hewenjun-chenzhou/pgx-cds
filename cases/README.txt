PGx CDS 病例库
====================

本目录用于存放电子版病例文本（.txt / .md / .csv）。

📁 命名建议：T<编号>_<药物/症状关键词>_<场景>.txt
   例：T6_CYP2D6_他莫昔芬无效.txt

📝 文件格式：自由文本，主诉/诊断/用药/化验任意排列
   支持自动识别的字段：
   - 诊断（如：诊断：肝硬化失代偿期）
   - 用药（如：用药：氯吡格雷 75mg QD；或 current_meds: clopidogrel）
   - 化验（如：ALT=150 U/L，CrCl=28 mL/min）
   - 症状信号（如：可待因镇痛完全无效 / 氯吡格雷抵抗 / 文拉法辛疗效差）

🎯 切换使用场景：
- 测试阶段 → 文件夹名用 "cases"
- 上线后   → 把文件夹改名 "病人病例" 即可直接用同一套逻辑导入真实病历
